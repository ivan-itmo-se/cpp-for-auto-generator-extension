# cpp for autogenerator extension

**VS Code расширение для автогенерации циклов `for` в C++.**

## Возможности

Генерация циклов `for` происходит в `.cpp` файлах при наборе соответствующих префиксов. После нажатия `Enter` на месте префикса появится почти готовый цикл.

Курсор автоматически встанет на место для ввода переменной, используемой для границ цикла. Отступ внутри цикла будет четыре символа, точка с запятой автоматичеки появится в конце строки.

**Всего доступно по две вариации цикла с переменными i, j, k: с возрастанием переменной и с убыванием.**

### Префиксы и результаты
- Обычные циклы (с возрастающей переменной)
  + `fori`:
  ```cpp
  for (int i = 0; i <  ; i++) {
      ;
  }
  ```
  + `forj`:
  ```cpp
  for (int j = 0; j <  ; j++) {
      ;
  }
  ```
  + `fork`:
  ```cpp
  for (int k = 0; k <  ; k++) {
      ;
  }
  ```
- Циклы с убывающей переменной
  + `fori-`:
  ```cpp
  for (int i =  - 1; i >= 0; i--) {
      ;
  }
  ```
  + `forj-`:
  ```cpp
  for (int j =  - 1; j >= 0; j--) {
      ;
  }
  ```
  + `fork-`:
  ```cpp
  for (int k =  - 1; k >= 0; k--) {
      ;
  }
  ```

---
Также доступна функция отправки сообщения от расширения при вводе `For Generator` в палитре команд (Ctrl (Cmd на Mac) + Shift + P).

## Установка
Установка доступна из *VSIX*.
